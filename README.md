# ESP32Authenticator

Hardware authenticator firmware for the **XTEINK X4 Pro Pocket eReader** (ESP32-S3, ESP-IDF).

- Encrypted storage of settings and credentials: site / login / password / TOTP / FIDO2.
- Credentials shown on the e-ink screen.
- Sent to the host via BLE keyboard (HID) or BLE FIDO2.
