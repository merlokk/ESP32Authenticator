# ESP32Authenticator

Hardware authenticator firmware for the **XTEINK X4 Pro Pocket eReader** (ESP32-S3, ESP-IDF).

- Encrypted storage of credentials: site / login / password / TOTP / FIDO2.
- Credentials shown on the e-ink screen.
- Sent to the host via BLE keyboard (HID) or as a FIDO2 / U2F key (BLE, USB).

User manual: [manual/README.md](manual/README.md).
